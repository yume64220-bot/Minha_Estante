Como instalar o aplicativo

O download é feito pelo GitHub. Depois de baixar, siga as etapas abaixo no seu dispositivo Android.

01

Baixe o APK

Toque no botão de download e aguarde o arquivo Minha-Estante.apk ser baixado.

02

Abra o arquivo

Localize o APK na pasta Downloads do celular e toque nele para iniciar a instalação.

03

Instale e abra

Se o Android solicitar autorização para instalar aplicativos dessa origem, confira a solicitação e permita apenas se confiar no arquivo. Depois, conclua a instalação.

Importante: o arquivo é um APK instalado fora da Play Store. O Android pode exibir um aviso de segurança. Baixe o arquivo somente do repositório oficial e confira as permissões solicitadas antes de instalar.
Dúvidas frequentes

O que você precisa saber

Informações úteis antes de baixar o Minha Estante.

O Minha Estante é gratuito?

O download disponibilizado neste site é gratuito. Consulte as informações da versão publicada para verificar eventuais alterações futuras.

Em quais dispositivos posso instalar?

O arquivo disponibilizado é destinado ao Android. A compatibilidade depende da versão do sistema e dos requisitos do aplicativo.

Como sei qual é a versão mais recente?

Acesse o histórico de versões no GitHub para consultar as publicações e suas informações.

Como atualizo o aplicativo?

Baixe a nova versão publicada e abra o APK para instalar a atualização. Para que ela seja aceita como atualização, a assinatura do aplicativo deve ser compatível com a versão instalada. Não desinstale a versão atual antes de verificar isso, pois os dados locais podem ser perdidos.

O download não funciona. O que faço?

Abra a página de Releases do projeto e tente baixar o arquivo APK diretamente. Se o arquivo não aparecer, verifique se existe uma versão publicada com o APK anexado.

Onde posso consultar o projeto?

O código e as publicações podem ser consultados no repositório Minha_Estante no GitHub.
